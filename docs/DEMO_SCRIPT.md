# 5-Minute Final Demo Script

1. **Login** — show the role-based dashboard.
2. **Content Studio** — create a draft and choose a visual cover.
3. **AI Studio** — generate a title/summary/body and analyze text for category, confidence, keywords, quality and readability.
4. **ML Research Lab** — run a category prediction and show the evaluation metrics, confusion matrix and model comparison.
5. **Approval Workflow** — submit a draft, approve it as Editor/Admin, then publish it.
6. **Article/API** — open the published article and the public REST feed.
7. **Analytics** — show lifecycle, category, quality and publication-health visualizations; export CSV as Admin.
8. **Audit Trail** — show that create/submit/approve/publish/upload/restore actions are recorded.
9. **Architecture/Research** — finish by explaining the headless architecture and the research limitation that the bundled ML dataset is only a demonstration dataset.
