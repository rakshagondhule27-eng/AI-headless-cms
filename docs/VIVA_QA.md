# Viva Questions and Short Answers

1. **What is a CMS?**  A system used to create, organize, manage and publish digital content.
2. **What is a Headless CMS?**  A CMS where the content/backend is separated from the presentation frontend and content is delivered through APIs.
3. **Why Flask?**  Flask is a lightweight Python web framework suitable for building backend routes and REST APIs.
4. **Why SQL?**  SQL provides structured, reliable storage for users, content, categories, versions and audit records.
5. **Why REST API?**  REST APIs allow the same managed content to be consumed by different applications.
6. **What is AI doing in the project?**  It assists with content generation, summaries, keywords, classification and quality analysis.
7. **What is NLP?**  Natural Language Processing is the processing and analysis of human language by computers.
8. **Why TF-IDF?**  It converts text into numerical features that can be used by traditional ML classifiers.
9. **Why Logistic Regression?**  It is efficient and works well as a baseline classifier for text features.
10. **What does the ML model predict?**  It predicts the category of a content item.
11. **What is Joblib?**  A Python utility used here to save and load the trained ML pipeline.
12. **What is RBAC?**  Role-Based Access Control restricts actions according to user roles.
13. **What is authentication?**  Verifying who the user is.
14. **What is authorization?**  Determining what an authenticated user is allowed to do.
15. **What is an audit trail?**  A record of important actions performed in the system.
16. **What is human-in-the-loop?**  AI provides assistance while authorized humans retain the final approval/publishing decision.
17. **Explain the architecture.**  Frontend → Flask Backend → AI/ML + SQL Database → REST API → Client applications.
18. **Why version history?**  To preserve previous content states and allow restoration.
19. **What is the main innovation?**  Combining Headless CMS architecture with AI/ML content intelligence and governed publishing workflow.
20. **What is the limitation?**  The included dataset is a demonstration dataset; final research evaluation should use a larger, properly sourced domain-specific dataset.
