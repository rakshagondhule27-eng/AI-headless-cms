## Before demonstration
1. Create a fresh Python 3.12 virtual environment.
2. Install `requirements.txt`.
3. Run `python ml/train_model.py`.
4. Run `python ml/compare_models.py`.
5. Run `python app.py`.
6. Login with the Admin demo account.
7. Demonstrate creating content and AI enrichment.
8. Submit a Draft for review.
9. Open Approval Workflow and approve/publish it.
10. Open Analytics and show database-backed values.
11. Open ML Lab and demonstrate prediction + metrics.
12. Open API Documentation and public feed.
13. Open Audit Trail and show recorded actions.
14. Test an image upload.
15. Run `pytest -q` before submission.

## Academic integrity
The included ML dataset is a demonstration dataset. Clearly label it as such in the report and presentation. Do not present its 100% metric as a production benchmark.
